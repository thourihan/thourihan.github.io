# Timothy Hourihan

A single-page personal website built with semantic HTML and one CSS stylesheet.
There are no build tools, JavaScript dependencies, or remote font requests.

## Preview

Open `index.html` directly, or serve the directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Edit

- `index.html`: content and page metadata
- `assets/css/main.css`: typography, colors, layout, and responsive styles
- `images/`: portrait and favicon

The `CNAME` file configures the GitHub Pages domain. Keep it, the page metadata,
`robots.txt`, and `sitemap.xml` consistent if the domain changes.
